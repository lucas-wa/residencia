# DENTRO do ambiente de GPU (container do cluster H100 e VM L4 da GCP), onde rodam o
# embedding e o ASR; estas deps sao do passo anterior, que nunca roda la:

#     audio_collector.py  URL publica -> audio local + record JSONL   <- yt-dlp

# Manter os dois separados evita (a) instalar yt-dlp na VM de GPU, onde ele nao serve para
# nada, e (b) meter mais um pacote na resolucao do pip daquele ambiente, que e exatamente
# o que o bloco no topo do requirements-slurm.txt pede para nao fazer. Nenhuma dep aqui
# arrasta torch.
#
#     pip install -r gcp/slice/requirements-collect.txt
#
# ffmpeg NAO entra aqui: nao e pacote pip, e requisito de SISTEMA do yt-dlp (extrair a
# trilha de audio e cortar com --max-seconds). Instale pelo gerenciador do SO --
# `sudo apt-get install -y ffmpeg` no Cloud Shell / Debian, `winget install ffmpeg` no
# Windows. Sem ele o yt-dlp baixa o container original e falha no postprocessor.
#
